# Bike_Sales_Dashboard

📊 Excel Dashboard Project
📌 Project Overview

This project is an interactive Excel Dashboard designed to analyze and visualize data effectively using Excel’s built-in tools.
The dashboard helps users track key metrics, identify trends, and make data-driven decisions through clear visual representations.

🎯 Objectives

Transform raw data into meaningful insights

Create a user-friendly and interactive dashboard

Practice real-world data analysis and visualization techniques in Excel

Present insights in a professional, decision-oriented format

🧰 Tools & Features Used

Microsoft Excel

Pivot Tables & Pivot Charts

Excel Functions (SUM, AVERAGE, IF, COUNTIF, etc.)

Slicers & Filters for interactivity

Conditional Formatting

Data Cleaning & Structuring

📁 Project Structure
Excel-Dashboard/
│
├── Excel Project Dataset.xlsx   # Raw & processed data
├── Dashboard Sheet              # Final interactive dashboard
├── Pivot Tables Sheet           # Backend calculations
└── README.md                    # Project documentation

📈 Dashboard Highlights

📌 Key Performance Indicators (KPIs)

📊 Interactive charts and graphs

🔍 Dynamic filtering using slicers

📉 Trend and comparison analysis

🎯 Clean and minimal visual design

🧠 Insights Generated

Identifies performance trends over time

Highlights top and bottom contributing factors

Enables quick comparison across categories

Helps stakeholders make data-backed decisions

▶️ How to Use

Download or clone the repository

Open Excel Project Dataset.xlsx in Microsoft Excel

Navigate to the Dashboard sheet

Use slicers and filters to explore insights dynamically
